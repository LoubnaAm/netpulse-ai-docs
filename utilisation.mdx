L'entreprise consulte une application web simple, comme un site internet interne, organisée en cinq pages.

<CardGroup cols={2}>
  <Card title="Supervision" icon="gauge">
    Vue d'ensemble de l'état du réseau, en direct.
  </Card>
  <Card title="Alertes" icon="bell">
    La liste des situations à surveiller, expliquées simplement.
  </Card>
  <Card title="Applications" icon="apps">
    Qui consomme quoi sur le réseau — sans jamais lire le contenu échangé.
  </Card>
  <Card title="Anomalies" icon="triangle-alert">
    Les comportements inhabituels détectés par l'IA.
  </Card>
  <Card title="Saturation" icon="chart-line">
    La prévision de charge du réseau dans les heures à venir.
  </Card>
</CardGroup>

<Note>
Aucune connaissance technique n'est nécessaire pour utiliser ces pages : les résultats de l'IA sont toujours présentés en langage clair, pas en code informatique.
</Note>
