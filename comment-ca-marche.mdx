Le projet repose sur trois grandes étapes, toujours dans le même ordre.

<Steps>
  <Step title="La collecte" icon="wifi">
    Les machines **satellites** (les ordinateurs du réseau que l'on surveille) observent en silence le trafic qui les traverse : combien de données, quand, et quel type. Elles ne lisent jamais le contenu des échanges.
  </Step>
  <Step title="L'analyse" icon="brain">
    Toutes ces observations remontent vers la machine **admin**, qui fait tourner trois intelligences artificielles pour comprendre les données : classification, détection d'anomalies, prévision de saturation.
  </Step>
  <Step title="L'affichage" icon="monitor">
    Les résultats sont présentés simplement dans une application web (comme un site interne), consultable depuis un navigateur, avec des graphiques et des alertes faciles à lire.
  </Step>
</Steps>

<Tip>
Pour comprendre la différence entre les deux types de machines en détail, va voir la page **Admin vs Satellite**.
</Tip>
